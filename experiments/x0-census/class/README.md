# X0 frozen classification inputs (record §4.4, §4.5, §4.7, §5 P3(a), §7)

Written on 2026-10-16 by the x0prep track, before any Hearth object exists. None of these files was derived
from a compiled Hearth object: the inputs are Hearth's SOURCE at b5d3f14, Intel's intrinsics XML (rust-lang/stdarch
copy), XED's own tables, and NON-Hearth smoke objects. Their SHA-256 values are listed in `../FREEZE.md` and in
`frozen_inputs.json` (which `judge.py` checks for V4). Evidence tags follow `docs/m0/README.md`.
