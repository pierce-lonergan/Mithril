# fp_flag_patterns.txt -- X0 record §5 P3(a): flag patterns that flag a configuration's effective FP settings.
# Frozen with the record (Appendix D, item D7). Evaluated by `x0_flags.py p3a` (function match_p3a).
#
# Format: one pattern per line, four TAB-separated fields:
#   id      unique name
#   class   a1 (contraction-enabling) or a2 (reassociation or value-unsafe)
#   source  comma-separated subset of: argv, cc1, gccq
#             argv = the exact compiler driver argv (A: cl line from the MSBuild log; A-ninja, B-cmake, C, D:
#                    compile_commands.json). Before matching, clang pass-through forms are also expanded:
#                    "/clang:X" and "-Xclang X" are matched as X as well.
#             cc1  = the -cc1 argv printed by `clang -###` / `clang-cl -###` (B-cmake, B-proxy, D, H-D).
#             gccq = one entry per option printed by `gcc <flags> -Q --help=common,optimizers` (C), normalised
#                    to "<option><TAB><value>" with surrounding whitespace removed. GCC 13 prints the option name
#                    with its value set, e.g. "-ffp-contract=[off|on|fast]\toff" and "-fassociative-math\t[disabled]"
#                    [M, x0prep, flags/C-gcc.*.gccq.txt, 2026-10-16].
#   regex   Python `re` pattern, matched with re.fullmatch against one token (argv, cc1) or one entry (gccq).
#           Case-sensitive unless the pattern starts with (?i).
# A configuration and file is flagged under P3(a) if any pattern matches any token or entry of a source the
# pattern names. Lines starting with '#' and blank lines are ignored.
#
# a1: contraction-enabling (record §5 P3(a1); 04-toolchain §6.2 forbidden list)
a1_msvc_fp_contract	a1	argv	(?i)[/-]fp:contract
a1_ffp_contract_on	a1	argv,cc1	-ffp-contract=(on|fast|fast-honor-pragmas)
a1_gcc_effective	a1	gccq	-ffp-contract=(\[[^\]]*\])?\t(?!off$).*
# a2: reassociation or value-unsafe (record §5 P3(a2))
